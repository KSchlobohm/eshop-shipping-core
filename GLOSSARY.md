# Glossary

| Term | Meaning |
|------|---------|
| Shipping API | The planned application programming interface for fictional eShop shipping operations. |
| .NET upgrade | Moving the sample to a newer .NET runtime; its starting version has not been selected. |
| Container validation | Checking that the application builds and runs in a container. |
| Dockerfile | A file describing how to build the application's container image. |
